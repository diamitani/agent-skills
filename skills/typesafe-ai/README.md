# typesafe-ai

Build typed AI judgments with boolean, choice, and score primitives. Combine deterministic validation, evidence-based model judgments, thresholds, and uncertainty escalation.

Canonical source: `SKILL.md`. Generated platform packs live under `dist/<platform>/typesafe-ai/`.

Personal project references have been removed. Credentials must remain in environment variables or a secret store, never in this repository.
